# Diabetes Prediction: From Data to Deployment

A complete MLOps project for predicting diabetes using Machine Learning and deploying the model with FastAPI.

---

# Project Overview

This project demonstrates the complete machine learning workflow:

- Data Cleaning & Preprocessing using Pandas
- Exploratory Data Analysis (EDA) using Matplotlib & Seaborn
- Training Multiple ML Models using Scikit-learn
- Model Evaluation & Selection
- Saving the Best Model using Joblib
- FastAPI Deployment with Pydantic Validation
- API Testing using cURL
- Version Control using Git & GitHub

Dataset Used:

`diabetes_unclean.csv`
